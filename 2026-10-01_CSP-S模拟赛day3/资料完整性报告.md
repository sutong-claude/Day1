## GitHub 推送限制

GitHub 连接器支持文本文件、分支、commit/PR 等写操作，但当前接口没有“从本地容器直接流式上传大二进制”的动作。把 27 MB VM ZIP、352 MB FLAC 或数 MB PDF 转成 base64 后直接塞进工具参数不现实。

因此仓库里优先保存：

- 所有关键源码 / 笔记；
- 完整题面文本；
- 复盘、题解、证明、结果核对；
- 原附件文件名 / 大小 / SHA256 清单；
- 可重复生成 / 验证的脚本与样例结果。

大二进制原件仍以本次用户上传文件为原始来源，不会假装已经推到 GitHub。
