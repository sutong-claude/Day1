# tree：N≤5000 暴力分支的最小语义反例

赛时代码：

```cpp
vis[i] = true;
d[i] = 1;
dfs(i, 0);
```

把起点的“当前访问时间”设成了0。

但题意要求起点也必须选择：

```
x_i ∈ [l_i,r_i]
```

反例：

```text
3
100 100
1 1
50 50
1 2
2 3
```

赛时代码输出3。

真实最优只有2：
- 1在100日访问后不能再访问只能在1日的2；
- 3在50日后也不能去2；
- 2→3 可以长度2。

因此小数据分支不能作为 oracle。

这是继 Day4 B 后第二个明确的“暴力程序本身漏题意语义”案例。
