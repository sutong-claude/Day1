# net：OJ100 代码的最小反例

赛时最终代码官方 20/20，榜单100。

但独立检查得到：

```text
3 1
1 2
2 3
```

正确答案：

```
1
```

因为只放一个路由器时放在2号房，1/3到最近路由器距离都为1。

赛时代码输出：

```
2
```

根因：

```cpp
road.push_back(0);
...
int len = road.size() - 1;
int pos = len / 2;
int root = road[pos];
```

`road[1..len]` 才是真实直径路径，奇数个顶点时 `len/2` 会偏一。

这就是仓库以后必须区分 `OJ-AC` 与 `PROVED` 的标准案例。
