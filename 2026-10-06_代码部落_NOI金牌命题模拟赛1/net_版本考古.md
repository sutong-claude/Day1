# 1. 为什么这个版本史很重要

如果只看最终源码，会以为：

> “想到直径中心，写完，AC。”

Replay 实际告诉我们：

```text
第一代模型 1.4KB
→ 本人不信
→ 连续砍到703B
→ 用直径框架重建
→ 再接上连通扩展
→ 最后IO
```

这证明 net 的100背后真正做对的一件事是：

> **敢推倒已经投入几十分钟的错误模型。**

# 2. Bug 的产生时间能精确定位

off-by-one 不是最终交付时才打错。

T1_07 首次出现：

```cpp
road.push_back(0);
...
int len = road.size() - 1;
int pos = len / 2;
int root = road[pos];
```

这之后 T1_08 只是把选 M 点的主体接上，T1_09 只加 IO。

所以 Bug 生命周期：

```text
产生：直径重建阶段 T1_07
↓
样例未暴露
↓
主体继续建立
↓
官方20/20仍未暴露
↓
赛后 n=3,M=1 最小反例暴露
```
