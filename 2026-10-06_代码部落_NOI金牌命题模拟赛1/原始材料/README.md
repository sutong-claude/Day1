# 原始材料说明

本场原始来源：

- 浏览器观察记录：比赛规则、四题题面、54人榜单、本人逐点评测；
- 两套录音转写/导读与智能概要；
- 457MB VM 战场；
- contest replay v3；
- 最终提交目录。

## 公开仓库隐私规则

不上传：
- 原始键盘流；
- clipboard；
- 屏幕录像；
- 未脱敏账号页面；
- 考号、账号敏感资料或与比赛分析无关的个人字段。

浏览器观察记录只提炼比赛统计，不原样公开。

## 为什么不直接把 VM 全塞进 GitHub

VM 里混有：
- 旧比赛文件；
- 旧样例残留；
- raw replay；
- 潜在私人信息。

仓库的目标是“下一位AI能接手”，不是“把硬盘镜像公开”。

因此采用：
**原件留文件库/本地 → 仓库保存脱敏索引、最终源码、时间线、验证结论。**
