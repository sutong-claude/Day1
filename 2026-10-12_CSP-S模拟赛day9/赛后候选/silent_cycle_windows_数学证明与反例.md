# D《静默能量》：函数图 + gcd 环分组 + 动态极大空白段（2026-10-15）

> 基于用户提供的 Gemini 对话 PDF **第20–22页**继续独立推导，特别补上“自然枚举环节点时滑窗并不连续”的隐含漏洞。本证明针对 PDF 所描述的**数学模型**；输入文件字段顺序/官方题面/OJ尚待服务端回读，因此只能标作本地实测候选，**不是 OJ-AC**。

## 1. 正确计算一个行（或列）的无噪声能量

若某行的噪声坐标为排序去重后的 `y_1<...<y_s`，插入哨兵 `y_0=0, y_{s+1}=m+1`，各极大安静段长度 `L_i=y_{i+1}-y_i-1`。

长度为 `L` 的安静段中，长度 `d` 的连续安静子区间有 `L-d+1` 个，能量为

```
F(L) = sum_{d=1}^L (L-d+1)*d*d
     = L*(L+1)^2*(L+2)/12
```

因此整行能量为 `ΣF(L_i)`。代码使用模 `998244353` 下的 `12^{-1}=582309206`，避免先取模再普通整除。

维护集合 `S={0,m+1}` 与每个真实噪声位置的命中次数 `cnt[y]`：

- 第一次插入点 `y`，原空白段 `(prev,next)` 被拆为两段，`energy += F(y-prev-1)+F(next-y-1)-F(next-prev-1)`；
- 最后一次移除 `y`，公式反向；
- 重复插入/移除仅维护计数，**不重复切分空白段**。

每次 O(log m)。

## 2. 两条函数图可以归约为尾链 + 环

沿初点在确定性映射 `P/Q` 下持续走，第一次重访后前半为尾链、后半为周期环。定义 `μ_x,λ_x` 和 `μ_y,λ_y`，以 `μ=max(μ_x,μ_y)` 为分界。

前 `min(k,μ)` 步可以直接生成不超过 `n+m` 个噪声格点，按行与列分别登记“尾链贡献”（即使一条轴已入环，也仍按前缀处理）。**这些前缀点以后还要与环产生的点取并集，不能直接把能量相加。**

若 `k>μ`，后续长度 `K=k-μ`；以 `t=μ` 为循环归零点，得到环序列 `cx[0..A-1]`, `cy[0..B-1]`，其中 `A=λ_x,B=λ_y`。环上格点在相对时刻 `t` 为 `(cx[t%A], cy[t%B])`。

## 3. 固定一行后，“巨大的 k”变成循环窗口

固定 x 环的余数位置 `r∈[0,A)`，该行被访问的时刻恰为：

`t=r,r+A,r+2A,... < K`。

次数

`q_r=min(B/g, floor(K/A)+[r < (K%A)])`，其中 `g=gcd(A,B)`。

上面的截断 `B/g` 是正确的：每隔 A 步，在 y 环走 `A mod B`，恰好遍历 **B/g 个互异** y 环位置，此后重复，再多的访问也不会产生新噪声位置。

将 y 环依模 g 分成 g 个类。对于类 `z=r mod g`，令 `h=B/g`，构造环排列：

`perm_z[j] = cy[(z+j*A) mod B]`，`j=0..h-1`。

因为 `gcd(A/g,B/g)=1`，每个类恰好是一个长度 h 的循环排列。行 r 的真实噪声点集合，就是该类排列上**从某个起点 p 开始、长 q_r 的连续循环窗口**。

起点 p 由同余式唯一确定：

`z + p*A ≡ r (mod B)`

约去 g：

`p ≡ ((r-z)/g) * inverse(A/g modulo h) (mod h)`。

这正是原 PDF 第21–22页“gcd 环滑窗”需要明确写出来的实现契约。

## 4. 一个很容易忽略的漏洞：不能直接按 r 从小到大滑窗

若 A=5、B=8，则 g=1, h=8，`inverse(5 mod8)=5`。按自然行余数 `r=0..4`，窗口起点 `p` 的顺序为：

`[0,5,2,7,4]`。

**这不是一个依次+1前进的窗口**。如果写成“下一行 r+1 → 删除旧窗口第一点、加入新窗口最后一点”，会漏删/漏插。尾链不同、g>1 时还会跨不同的子环。

修正：**先按 g 类划分各行请求，再按 p 排序处理**。每个请求附带行 r 和窗口长度 q_r。

排序后的 p 非降。由于 q_r 只有 `base`、`base+1` 两种取值（截断后依旧最多相差1），当 p 严格增加时，右端点 `p+q_r` 不会后退；但 A>B 时**不同 r 可能具有相同 p**，此时 q 可能从 base+1 降到 base，需要允许右端回退1。实现中左右端都按需要动态 insert/erase。

总的左右端移动次数为 O(A+B)；同类 y 序列初始化长度总和为 `g*(B/g)=B`。**不能**对每一行重新枚举自己的 q_r 个噪声点，否则可能退化为 O(A*B/g)。

## 5. 与前缀噪声格点合并，保证不重复计算

先在所有行/列用前 μ 步格点求 `baseline[row]` 与 `baseline[col]`：

- 如果某行不是周期中的行，**全程保持 baseline**；
- 对周期中的行，根据环窗口维护其周期噪声位置，临时再插入该行所有前缀噪声位置（通过 cnt 消除重复），得到 `actualRow`；
- 全局答案从 `baselineRow` 中减掉该行旧贡献，再加 `actualRow`，随后撤销该行的临时前缀噪声，以复用同一个周期窗口集合；
- 对列方向交换 x/y、n/m 做完全相同操作。

两方向求和取模，即所有行、所有列的静默子区间能量和。

## 6. 复杂度、边界和独立真值

在本模型输入范围 `n,m≤10^5` 下，尾链格点最多 `O(n+m)`；两方向分组排序共 `O((n+m)log(n+m))`，循环窗口滑动、集合插删和前缀注入合计同阶；整体

**时间 `O((n+m)log(n+m))`，空间 `O(n+m)`（不展开 n*m 个格点）**。

确切要求：
- `k=0`：所有格点安静；两个方向的基础贡献保留；
- `k≫lcm(A,B)`：`q_r≤B/g` 去重，不得模拟所有时刻；
- `A>B` 和重复 p：滑窗可能缩回；
- 不等长尾链、尾链格点与周期格点重合：cnt 必须去重；
- 动态集合有 0 和 长度+1 的两个哨兵；
- 每个维度的贡献分别计算；最终不是“全局已出现哪些 x/y 标签”，而是按每行、每列的噪声点二维关联计算。

**真值脚本**：[test_silent_cycle_windows.py](test_silent_cycle_windows.py) 用一个完全不同的算法：逐格点模拟，遇到第二次出现相同 `(x,y)` 时即可停止（后续格点必然重复），建二维格点集合，然后直接枚举每行/列的排序空白段。这套 oracle 没使用 gcd、倒数模运算、滑窗或线段树。
