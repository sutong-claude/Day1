# A A 乘法

# 乘法

现在我们想用加法、减法和左移来模拟乘法。具体的，对于一个算式 x×ax\times ax×a，我们想把它替换成 $(x << a_0) op_1 (x << a_1) op_2 \dots op_n (x << a_n)$ 的形式，其中 opiop_iopi​ 必须是加法或者减法。

对于任意的左移（包括左移 000 位）、加法、减法都需要花费 111 单位的时间计算。

给定 aaa 的二进制表示，请问最少需要多少单位的时间进行计算。

#### 输入格式

从文件 `multiply.in` 中读入。

一行一个 010101 串，表示 aaa 的二进制表示（左边为高位，右边为低位）。

#### 输出格式

输出至文件 `multiply.out`。

输出一个整数，表示答案。

#### 样例输入1

```
1111
```

#### 样例输出1

```
3
```

#### 样例解释1

x * 15 = (x << 4) - (x << 0)

一共需要 333 单位的时间。

见附加文件。[点击下载附件文件](https://newoj.daimayuan.top/p/185/file/problem_185.zip?tid=6ab75554b8c09340fef56fe3)

- 1≤∣a∣≤1061\leq |a| \leq 10^61≤∣a∣≤106，并且第一位不为 000。

# C C 🔴

# 🔴

你有一个长度为 nnn 的序列。其中每个位置包含若干个棋子，棋子可能是红色，黄色，蓝色中的一种。保证每个位置至少有一个棋子，并且同一个位置上的棋子的颜色两两不同。

你希望把序列分成若干个连续段。一个段是好的，当且仅当这个段里面所有格子的红色棋子个数大于等于黄色棋子，并且红色棋子个数大于等于蓝色棋子个数。

你想知道，分段之后好的段的总长度最长是多少。

### 输入格式

从文件 `chess.in` 中读入。

第一行输入一个整数 nnn。

接下来一行，一个长度为 nnn 的数字串 s1s2…sns_1 s_2 \dots s_ns1​s2​…sn​。其中 si=4ri+2yi+bis_i = 4r_i + 2y_i + b_isi​=4ri​+2yi​+bi​，ri,yi,bir_i, y_i, b_iri​,yi​,bi​ 分别表示这个位置的红色，黄色，蓝色的棋子个数。

### 输出格式

输出至文件 `chess.out`。

输出一个数，表示答案。

## 样例输入与输出

### 样例输入 1

对每组数据，请确定每个人是不是狼人，如果有多种可能性，给出任意一种可能即可。或者说信息互相矛盾，即不存在一个合法的分布。

否则输出一个长度为 nnn 的 010101 串，其中第 iii 位为 000 表示第 iii 个人为村民，否则为狼人。
