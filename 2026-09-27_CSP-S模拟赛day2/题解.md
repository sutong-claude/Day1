## A　乘法

**题意**：把 x × a 写成 (x<<a₀) ± (x<<a₁) ± … ± (x<<aₖ)，每次左移、加、减都花 1。给 a 的二进制（≤ 10⁶ 位），求最小花费。

**转化**：用 k 项的花费是 k 次左移 + (k−1) 次加减 = **2k − 1**。问题变成：a 最少写成几个 ±2ᵗ 的和。

**关键性质**：最优写法里同一个 2ᵗ 最多出现一次（两个同号能合并成 2ᵗ⁺¹，异号直接删掉，项数都变少）。所以每一位只能填 **−1、0、+1**。

### 部分分

- 子任务 1（|a| ≤ 10，20 分）：a ≤ 1023。写成 a = (a + b) − b，枚举负项之和 b（0～4a+4），项数 = popcount(a + b) + popcount(b)，取最小。见 `暴力/A_暴力.cpp`。

### 正解：带进位的数位 DP，O(|a|)

从低位往高位填。设当前位原来是 bit，低位传上来进位 c ∈ {0, 1}，v = bit + c：

| v | 这一位填 | 往上进位 | 项数 |
|---|---|---|---|
| 0 | 0 | 0 | +0 |
| 1 | +1 | 0 | +1 |
| 1 | −1（借 2） | 1 | +1 |
| 2 | 0 | 1 | +0 |

f[c] = 处理完当前位、往上进位为 c 时的最少项数。最后 k = min(f[0], f[1] + 1)（剩下的进位再补一项 +2ⁿ），输出 2k − 1。

**为什么对**：每一种“每位填 −1/0/+1”的写法都对应表里一条从左到右的路；走到同一格（同一位、同一进位）以后，后面怎么填完全一样，所以每格只留最少的，不会漏掉最优。

**为什么进位只有 0、1**：v 最大是 1 + 1 = 2，填完进位最多 1。

代码：`正解代码/A_乘法.cpp`。

### 另外三种做法（结果都一样，已对拍）

| 做法 | 一句话 | 代码 |
|---|---|---|
| 从低位贪心（NAF） | v = 1 时看高一位：高一位是 1 就填 −1 进位，否则填 +1 | `A_其他做法/A_从低位贪心.cpp` |
| 公式 | 项数 = popcount((3a) xor a)，3a 用高精度加法 a + 2a | `A_其他做法/A_3a异或a.cpp` |

## B　🧶

**题意**：n 个串依次加入。f(i, j) = 从前 i 个串里挑 j 个，公共前缀最长多长。对每个 i 输出 Σⱼ₌₁ⁱ (f(i, j) xor j)。n ≤ 5×10⁵，Σ|s| ≤ 10⁶。

### 部分分

- 子任务 1（n ≤ 10，10 分）：枚举子集，按定义算。见 `暴力/B_暴力.cpp`。
- 子任务 2（n ≤ 5000，30 分）：下面的 mx[d] 每次都重算所有 f(j)，O(n · 最大深度) 或 O(n²)。

### 正解：字典树 + 增量维护，O(Σ|s|)

1. **把 f 翻译到字典树上**：挑 j 个串能有长度 ≥ d 的公共前缀 ⇔ 第 d 层有某个结点被 ≥ j 个串经过。
   设 mx[d] = 第 d 层所有结点里最大的经过次数，则 **f(j) = 满足 mx[d] ≥ j 的最大 d**。
   （mx[d] 随 d 不增。把 mx[d] 画成第 d 行的格子数，f(j) 就是第 j 列的高度。）
2. **插入一个串，mx 怎么变**：它经过的每一层只有一个结点 +1，所以每层 mx 最多 +1。
3. **mx[d] 从 m 变 m+1 时，只有 f(m+1) 会变**：
   - j ≤ m：本来就 mx[d] ≥ j，不变
   - j ≥ m+2：仍然 mx[d] < j，不变
   - j = m+1：从不满足变成满足，f(m+1) 更新为 max(f(m+1), d)
4. **答案不重算**：和 ans 一直存着。改一格 f[j] 时 `ans -= f[j] ^ j; f[j] = d; ans += f[j] ^ j;`。新加入第 i 个串时先加上新的一项 `0 ^ i`。

每个串最多改 |s| + 1 格，总 O(Σ|s|)。

**样例 1 最后一步**（f 从 [3,2,1] 到插入 abcd）：+4 → 8；f₄ 0→1 → 9；f₃ 1→2 → 8；f₂ 2→3 → 9；f₁ 3→4 → **12**。

代码：`正解代码/B_毛线.cpp`。讲解视频：`讲解视频/B_毛线_为什么不用重算每个f.mp4`。

**识别信号**：“对每个前缀都输出答案” → 想增量：加一个元素，哪几项会变。“f(j) = 最大的 d 使 g(d) ≥ j” → f 和 g 互为转置，g 的一次 +1 只改一个 f。

## C　🔴

**题意**：长度 n 的序列，每格有红/黄/蓝棋子各 0 或 1 个（至少一个）。分成若干连续段，一段“好”当且仅当段内红 ≥ 黄且红 ≥ 蓝。求好段总长最大。n ≤ 2×10⁶。

### 第一步：改写条件

X[i] = 前 i 格的（红 − 黄），Y[i] = 前 i 格的（红 − 蓝）。段 (j, i] 好 ⇔ **X[j] ≤ X[i] 且 Y[j] ≤ Y[i]**。

### 第二步：DP 和部分分

f[i] = max( f[i−1],  max{ f[j] + i − j : j < i, X[j] ≤ X[i], Y[j] ≤ Y[i] } )。

- 子任务 1、2（n ≤ 5000，30 分）：直接 O(n²)。见 `暴力/C_暴力.cpp`。
- 子任务 3（n ≤ 2×10⁵，再 +30 分）：令 g[j] = f[j] − j，式子变成 **i + 左下方最大的 g**。条件是 j < i、X[j] ≤ X[i]、Y[j] ≤ Y[i]，三维偏序 → **CDQ 分治**：按下标分治，先算左半，把左半的点按 X 排序、用树状数组（下标 Y）维护前缀最大 g，更新右半；注意 f 是在线的，要“左 → 跨 → 右”的顺序。O(n log²n)。练习：洛谷 P3810。

### 满分：用题目特有的结构，O(n log n)

令 u[i] = i − f[i]（前 i 格里最少有几格不在好段中），转移变成 u[i] = min(u[i−1] + 1, 左下方点的最小 u)。

1. **每一步的方向**：有红子的格子 X、Y 都不减（往右上走）；没红子的格子 X、Y 都不增、且至少一个减（往左下走）。
2. **往右上走**：上一步的点 i−1 就在左下方（单个红格本身是好段），所以 u[i] ≤ u[i−1]；新进入左下方的点只可能在**当前这一列 x = X[i] 或这一行 y = Y[i]**。每列、每行各开一个有序表，查“这一列中 y ≤ Y[i] 的最小 u”。
3. **往左下走**：左下方只会变小，u[i] 只能是 u[i−1] 或 u[i−1] + 1。只需判断“有没有 u 值恰好等于 u[i−1] 的点在左下方”。每个 u 值维护一条阶梯（极小点集合，x 递增 y 递减），查一次即可。
4. **只存必要的点**：红格和“u 没变”的格子，它的 u 都能由一个它支配的旧点作证，不用存；只有“没红子且 u 变大”的格子才存进三个表。

代码：`正解代码/C_棋子.cpp`（2×10⁶ 各种分布最慢约 0.4 秒，和 O(n²) 对拍 900 组）。

> 赛后唯一补出满分的人用的是 CDQ + 卡常（用户口述）。O(n log²n) 在 2×10⁶ 上本来很危险，不建议学这条路。

## D　🐺

**题意**：n 个人一排，村民说真话，狼人可真可假，狼人不相邻。第 i 人说“左边（L）/右边（R）有 bᵢ 个狼”。给出任意一种合法分布或 −1。Σn ≤ 2×10⁶。

### 部分分

- 子任务 1（n ≤ 10，10 分）：枚举 2ⁿ 种分布逐个检查。**注意取满 n 位**：`for (k = 0; k < n; k++) w.push_back (i >> k & 1);`。见 `暴力/D_暴力.cpp`。
- 子任务 2（全是 L，15 分）：从左往右，每人两种状态：
  - 村民：到自己为止的狼数 = bᵢ（他说的是真话）
  - 狼：前一个必须是村民，到自己为止的狼数 = b(i−1) + 1
  两种状态下“到自己为止有几个狼”都是确定的，转移时检查前一个人的数接不接得上。O(n) DP，记前驱回溯方案。

### 正解：枚举狼的总数 W，O(n log n)

1. **村民连成一条链**：狼不相邻 ⇒ 相邻两个村民之间最多夹一个狼。加两个虚拟村民 0 和 n+1，一种分布就是一条 0 → n+1 的路，每步走 1 或 2（走 2 表示中间那个是狼）。
2. **狼只要不相邻就合法**（狼可以说假话），所以只需检查村民的话。
3. **一条边 i → j 能不能走**（g = j − i − 1 为中间狼数）：
   - 都是 L：b[j] = b[i] + g，和 W 无关
   - 都是 R：b[j] = b[i] − g，和 W 无关
   - **一个 L、一个 R：只有一个 W 能走**（L→R：W = b[i] + g + b[j]；R→L：W = b[i] + b[j] − g）
   - 虚拟端点同理
4. **枚举 W**：和 W 无关的边一直开着；每条“挑 W 的边”只在枚举到它的 W 时打开。把每个位置写成 2×2 布尔矩阵（能否从 j−1、j−2 到达），线段树维护乘积。每个 W 打开它的边 → 看终点能否到达 → 关上。边一共 O(n) 条，总 O(n log n)。
5. 找到 W 后，普通 DP 回溯出一条路即为方案。n = 1 时一个人当狼永远合法。

代码：`正解代码/D_狼人.cpp`（和穷举对拍 10500 组，Σn = 2×10⁶ 最慢 0.43 秒）。

**识别信号**：有一个“全局未知量”（总狼数）→ 看它在哪些地方被钉死；只在少数地方被钉死，就枚举它、每次只改那几处。
