### B 🧶（0 分，未交）

**题目本质：** 对每个 i，f(i, j) = 前 i 个串里选 j 个的最长公共前缀，求 ∑ⱼ f(i, j) xor j。

**你的思路复原：**

- 11:41 字典树，选 j 个串就是找一个结点，它下面至少有 j 个串 ✓
- 11:42 想二分深度
- 11:45 **“我给每一层求个最大值”** ✓✓
- 11:49 **“插入一个串，这条路径上全加一，然后每一层都要取一遍最大值”** ✓✓
- 11:50 “如果字典树退化成链……难办了……复杂度差得远” ✗
- 12:45 “你是怎么做到不挨个算就能知道的？”

**你已经有的：** 设 `mx[d]` = 深度 d 上经过次数最多的结点的次数。那么 **f(i, j) = 最大的 d，使得 mx[d] ≥ j**。这就是你 11:45 说的“每层最大值”。

**你卡住的第一处——复杂度估错了：** 插入第 i 个串只会经过 |sᵢ| 个结点，每个结点 +1，每层最多一个结点变。所有串加起来 ∑|sᵢ| ≤ 10⁶。**退化成链也一样**：链长就是串长。估复杂度要按“总和”算，不要按“最坏一次 × 次数”算。

**你卡住的第二处——“不挨个算怎么知道”：**

- 插入一个串时，每层的 `mx[d]` 最多 +1
- `mx[d]` 从 m 变成 m+1，只影响一个 f：**f(m+1) = max(f(m+1), d)**。因为 f(j) 的定义里只有 j = m+1 这一个条件变了
- 所以答案可以增量维护：改之前减掉 `f xor j`，改之后加回来
- 每个 i 还要新加 j = i 这一项，它一开始是 `0 xor i`

一共改 ∑|sᵢ| 次，O(∑|sᵢ|)。核心就这几行（完整代码 `正解代码/B_毛线.cpp`）：

```cpp
ans += (0 ^ i);
for (int d = 0; d <= len; d++) {
    // u 走到第 d 层的结点
    cnt[u]++;
    if (cnt[u] > mx[d]) {
        mx[d] = cnt[u];
        int j = mx[d];
        if (d > f[j]) {
            ans -= (f[j] ^ j);
            f[j] = d;
            ans += (f[j] ^ j);
        }
    }
}
```

大样例 5 个全过，最大的 0.25 秒。

**稳拿的 10 分：** 子任务 1（n ≤ 10，|s| ≤ 50）按定义暴力，`正解代码/暴力/B_暴力.cpp` 30 行。你 14:01 说“性价比不高”——10 分钟 10 分，比 D 那 5 分钟写错的 solve2 性价比高得多。

**下次识别信号：**

- “对每个前缀 i 都要输出答案” → 想增量：加一个元素，哪些量会变、变多少
- “f(j) = 最大的 d 使得 g(d) ≥ j” → f 和 g 互为“转置”，g 的一次 +1 只改一个 f

**为什么 2×10⁵ 和 2×10⁶ 有区别（你 12:05 问的）：** 2×10⁵ 允许 O(n log²n)（二维偏序，CDQ 分治），可以拿 60 分；2×10⁶ 在 1 秒内只能 O(n) 或很轻的 O(n log n)，必须找题目的特殊结构。

**正解思路（供了解，现阶段拿 30 分就是对的）：**

1. 设 u[i] = i − f[i]，意思是“前 i 格里最少有几格不在好段里”。转移：u[i] = min(u[i−1] + 1, 所有 X[j] ≤ X[i] 且 Y[j] ≤ Y[i] 的 j 的 u[j])
2. **特殊结构：** 有红子的格子，X、Y 都不减；没有红子的格子，X、Y 都不增、且至少一个减。点 (X, Y) 每一步要么往右上走、要么往左下走，两维永远同方向
3. 往右上走时，新“看得到”的点只在一列和一行上 → 每列、每行各维护一个有序表
4. 往左下走时，u 只可能不变或 +1 → 只要判断“有没有 u 值等于当前 u 的点在左下方”→ 每个 u 值维护一条阶梯（极小点集合）
5. 只有“没红子而且没被覆盖”的格子才需要记下来

### D 🐺（0 分，TLE 然后 CE）

**题目本质：** 村民排成一条链，相邻两个村民之间最多夹一个狼。左看的村民定死了“前面有几个狼”，右看的村民定死了“后面有几个狼”。

**14:01 那版暴力为什么 0 分：**

```cpp
int t = i;
wolves.clear();
while (t != 0) {
    wolves.push_back(t % 2);
    t /= 2;
}
```

`wolves` 的长度是 `i` 的二进制位数，不是 n。`isValid` 第一句就检查长度，长度不够直接 false。结果**只有最高位是 1（第 n 个人是狼）的分布被试过**，“全是村民”（i = 0）也从没试过。

- 题面样例三组答案：`001`、`-1`、`10101`——恰好最后一个都是狼或者无解，所以**样例过了**
- 大样例 sample2 就是子任务 1 的 1000 组数据，一跑就错 277 组。你下载了，没跑

改法：`for (int k = 0; k < n; k++) wolves.push_back (i >> k & 1);`。改完就是 10 分。

**14:09 那版为什么 CE：** `solve` 里调用了 `solve2`，但 `solve2` 写在 `solve` 下面，没声明。桌面上 `T4` 可执行文件是 14:00 编译的，`T4.cpp` 是 14:09 改的——**交之前没编译**。而且就算编译过了，`if (n > 20) solve2 (n);` 后面没有 `return`，还会接着跑 2ⁿ 暴力。

**子任务 2（全是 L，15 分）怎么做：** 左看的村民 i 要求“前面恰好 bᵢ 个狼”。从左往右，每个人两种状态：

- i 是村民：前面的狼数必须等于 bᵢ
- i 是狼：i−1 必须是村民，前面的狼数 = b(i−1) + 1

每个状态的狼数都是确定的，O(n) DP。你 12:52 说的“第一个人肯定说 0”就是这个 DP 的第一步。

**正解（供了解）：**

1. 如果知道狼的总数 W，右看的村民也能换成“前面有 W − bᵢ 个狼”，就是上面那个两状态 DP，O(n)
2. 看相邻两个村民 i → j（j = i+1 或 i+2）：
    - 都左看：b[j] = b[i] + 中间狼数，和 W 无关
    - 都右看：b[j] = b[i] − 中间狼数，和 W 无关
    - **一左一右：只有一个 W 能走**（左→右：W = b[i] + b[j] + 中间狼数；右→左：W = b[i] + b[j] − 中间狼数）
3. 所以一共只有 O(n) 条“挑 W 的边”。把每个位置“能不能从前一个、前两个村民走过来”写成 2×2 的 0/1 矩阵，线段树维护乘积；枚举 W 时只把这个 W 的边打开、看能不能走到终点、再关上。O(n log n)
4. 找到 W 后普通 DP 回溯出方案；n = 1 时一个人当狼总是合法

大样例全部用 checker 规则校验合法；和穷举暴力随机对拍 10500 组（包括判 −1）全对；∑n = 2×10⁶ 最慢 0.43 秒。代码 `正解代码/D_狼人.cpp`。

**下次识别信号：** 有一个“全局未知量”（这里是总狼数）→ 看它在哪些地方被钉死；如果只在少数地方被钉死，就枚举它、每次只改那几处。

### 题型规则（写进执行卡）

1. 二进制 + 加减 + 最少项数 → 数位 DP，状态记进位
2. 写出等式 → 枚举一边就是暴力
3. 估复杂度按“总和”：字典树插入总代价 = ∑|s|

5. 枚举 n 位的 0/1 分布：`mask >> k & 1`，k 从 0 到 n−1

1. 对拍前 `cat 1.txt` 看一眼输入不是空的
2. 题面样例过了不算，大样例全跑一遍
