## A 档案 [P,E,C]

设核心编号为 a，某批 B 对所有核心位置的总增量为
`w(B)=sum_{x in B} #{a_j>x}`。该增量不依赖别批先后顺序。第 t 批被处理后在后续 m-t 次操作中仍持续贡献，总贡献为 `w(B)*(m-t+1)`。每次核心自身下标和的常量是 `n(n+1)/2`。所以
`answer=m*n(n+1)/2 + sum_{t=1}^m (m-t+1)*w(B[t])`。
交换相邻两批 X,Y，若 w(X)>w(Y)，将较小者放前会令总和下降 w(X)-w(Y)，故按权重升序。排序核心编号后用二分累计，O((n+L) log n+m log m)。注意一次批次的 w 可能达到 1e12，须 long long。

## B 函数 [P,E,C]

原卷是 `OR(S) | MEX(S)`，不是 `OR(S)*MEX(S)`，注意甄别第三方纪要错误。

设 MEX=k。由于 0,1,...,k-1 全在 S，若 k 不是 2 的正整数次幂，则 k 的每个二进制 1 位已经在 `OR(0..k-1)` 中出现。唯一可能额外增加的位是 `k=2^b` 对应的第 b 位。

基线所有子区间 OR 求和：设 `last[b]` 是第 b 位最近一次出现的位置，固定右端点 r，第 b 位在 `last[b]` 个子区间出现，故逐 r 累加 `2^b*last[b]`。

修正部分按每个 `2^b<=n` 枚举，要求：区间包含全部 `0,...,2^b-1`；区间任何数都不设置第 b 位。后一条件自然排除 `2^b`，因此此时 MEX 恰为 `2^b`；使用屏障分段+滑动窗口统计所有合法区间，修正 `2^b` 倍。用时间戳标记清桶，以免出现每次屏障 O(2^b) 的错误。答案用 unsigned long long 自然模 2^64。复杂度 O(30n + n log n)。

## C 路短最 [P（局部模型）+E（完整程序）]

赛时源码使用了 `priority_queue<pair<ll,ll>,...,greater<...>>`，这实际上取**距离最小**而非题意要求的最大值：即使能输出 n，也不是题目要求的模拟。修正堆顺序可对拍，但原题大样例一次输出可达数十亿，暴力堆模拟不能做满分。

独立研究模型：

1. 对仙人掌建 DFS 树。每条返祖边对应唯一简单环；树路径上每条边至多属于一个环，因而所有展开过程总线性。用圆方意义上的根 u 连接其环上所有其余节点。
2. 当某个环根的最短距离按 `D_0>D_1>...>D_s` 依次降低，记下降量多重集合 `{D_{j-1}-D_j}`。一个**每次只随根修正一次**的普通后代得到相同的下降量集合。
3. 环长度 L，第一条展开方向由进入点两个环邻居的编号大小确定。对该方向上的位置 i：若 `i=L-1`（另一个初始直接邻居）或 `2i<=L`，下降集合不变；如果 `2i>L` 且 `i<L-1`，令 `h=2i-L>0`。该点第一次访问先走 i 步再被环另一侧的 L-i 步修正，额外得到下降 h。此后根下降一个 gap=Δ 时，若 Δ>h，先经长度 i 更新再经长度 L-i 更新，间隔 Δ 被分为 `Δ-h` 和 `h`；否则只从短方向修正一次，gap 保留 Δ。
4. 因此新多重集合从父集合对每个 Δ>h 作分裂 `Δ -> (Δ-h, h)`，再额外加入一个 h。节点被处理次数是多重集合元素总个数+1。实现用全局 map 和显式 DFS 回滚，保证不同子树的状态不会互相污染。
5. 模型对 10000 个小仙人掌随机与独立堆模拟一致；C++ 实现在 path1~5 及 1000 个独立随机图与事件模拟一致。[E] 但请保留全局调度证明审计、对抗性能压测作为下一关卡。

## D 大雨 [P（两值界）+E（小值域）]

定义 `d_i=a_i xor a_{i+1}` (i<n)，`d_n=a_n`。一次前缀异或 (p,x) 仅使 `d_p` 异或 x，其余差分不变。

如果一个连续段内相邻差分全部不修改，就存在同一掩码 z 把整个段原值异或成不降序列。对相邻不等项 x,y，设 j=msb(x xor y)，则要求 z 的第 j 位等于 x 第 j 位。不同相邻对在同一 j 上要求相反值时，该段不可能一次整体异或排好。性质可用贪心求整个数组最少这样的段数 k。

任意合法方案如果在 n 位置无操作，则 m 次操作最多分割成 m+1 个不变掩码段，因而 m>=k-1。若在 n 位置发生操作，则 m 次操作最多分为 m 个连续段，因而 m>=k。

反过来，取 k 段各自满足的低 30 位掩码，并给每个段额外安排严格递增的高位等级（原始数均小于 2^30，操作 x 不设上界），可确保段间大小严格递增且段内顺序不变。总共 k-1 次内部边界前缀操作、至多一次 p=n 的整体操作。因此 `k-1<=answer<=k`，精确答案只可能两值。

剩余关键难题：固定最后一个数 b_n=a_n、**禁止对 n 操作**的条件下，能否只用 k-1 个内部边界操作。小值域可做精确 DP，令 G_i(v) 是构造不降后缀 b_i..b_n 且 b_i=v 的最少内部编辑数，令 diff=a_i xor a_{i+1}。转移为：
`G_i(v)=min( G_{i+1}(v xor diff) [v<=v xor diff], 1+min_{t>=v}G_{i+1}(t) )`。
初态 G_n(a_n)=0，其余 INF，且由于全序不降，所有 b_i<=a_n；可在 O(n*(a_n+1)) 的小值域下精确判定，再与上界 k 取 min。大值域直接返回 k **并不保证正确**。完整解仍未解决，故部分分程序明确标注 NOT_FULL。

### D 的一条已经构造出来的贪心反例 [X]

不能按“从右端开始，尽量保留最长的原样不降后缀，然后再切一段”的方式判断 k-1。反例 `a=[2,1,0,3]`：最长原样不降后缀是 `[0,3]`，它要求此前的两个互不相同的数通过同一个掩码都落在不大于 0 的位置，不可行；但仅操作一次 `(p=3,x=3)` 就得到 `[1,2,3,3]`，真实答案为 1。必须允许主动在本来单调的后缀内部设分割点，所以“取最长有效段”式后向贪心会错。这条反例已与小值域精确 DP 核对。

### 第二套精确部分分：小 n、30 位值域仍可解 [P]+[E]

当 n<=17 而 a_n 接近 2^30，直接值域 DP 不能用。按**未修改的差分边**将序列分块，对每一块 [l,r] 选择固定 XOR 掩码 z。块内相邻不同元素的最高不同位给出 z 的强制 bit；发生冲突则整块不可行。令 suffixDP[l][j] 表示固定末尾 b_n=a_n、用恰好 j 个内部边界修改，使后缀 [l,n] 非降时，最大可以达到的首元素值 b_l（-1 不可行）。把状态只保留最大 b_l 正确：供它左边的分块拼接时，界限越大可选方案越多，其他内部细节不影响左边。

对右端点 r<n 的一个新块 [l,r]，令 U=suffixDP[r+1][j]，需要最大化 `b_l=a_l xor z`，同时满足块内 bit 约束和 `b_r=a_r xor z <= U`。令 y=a_r xor z，目标等价于在 `0<=y<=U`、某些 y 的 bit 固定的条件下，最大化 `y xor (a_l xor a_r)`；逐位 tight/not-tight 数位 DP O(30)。因此状态转移为 `suffixDP[l][j+1] = max_{r≥l} optimizeBlock(l,r,suffixDP[r+1][j])`。末尾块 [l,n] 必须 z=0，所以只有原序列 a_l..a_n 已非降时 `suffixDP[l][0]=a_l`。对每个 r,l 更新块 bit 约束，O(n³*30) 时间、O(n²) 内存，n≤17 实测足够。

最终与 k 比较，返回 `min(k,smallNExact)`。独立于值域 DP，在长度 1..7、每项 0..3 的全部 **21,844** 个数组以及另外 1,760 个随机数组中，两种精确算法完全一致。[E]

与值域 DP 合并后的官方附件重新逐组对照：rain1～7 全对；rain8 97/100，rain9 80/100，rain10 83/100，rain11 82/100；其余错误是主动在大型不可解情况返回上界 k，**不是程序崩溃或已解决的大数据**。

### 有界窗口 DP 不完备的具体反例 [X]

`验证/rain_known_failure_48.in` 有8个各重复6次的原数：`537171611 411468790 360777006 75846127 853841845 721910029 726723669 1033208060`。共48个数，k=3。长度8/额外成本状态2档的截断 DP 及单一路径的贪心构造证书均失败，退回输出k=3；然而无窗口限制的精确区间 DP 可以用2次操作完成。

这说明代码所谓“构造证书”严格只是可行性证明而非充要条件；即使全部提供的附件测试组通过，也不能转称数学意义的满分解法。
