# OI Contest Review v2

## 触发

用户说以下任一意图时使用：

- “复盘这场比赛”
- “老规矩分析”
- “看看我怎么想的”
- “完整吃下归档/虚拟机/录音”
- “阶段回顾”
- “为什么这题没想到”
- “分析模拟赛全过程”

# 核心原则

1. **证据先于评价。**
2. **用户赛时思路先于标准题解。**
3. **错误方法为什么诱人，必须解释。**
4. **最终代码不是全过程。**
5. **录音、Replay、代码版本、提交互相校验。**
6. **赛后 hindsight 与赛时已知严格分开。**
7. **OJ-AC 不等于 PROVED。**
8. **仓库落盘后才能说“已更新”。**
9. **后面的比赛不得比前面的黄金样例缩水。**

# 工作流

## Phase 1：材料审计

列：
- 题面；
- 子任务；
- OJ归档；
- 榜单；
- 提交/逐点；
- VM；
- 录音；
- Replay；
- notes；
- checker/sample/data；
- 草稿；
- 最终提交目录。

ZIP递归展开。

输出：
- 已读；
- 未读；
- 冲突；
- 可信度；
- 私有/可公开边界。

## Phase 2：Replay

v3：
1. timeline
2. file_changes
3. screen
4. raw_keys
5. manifest

screen 负责 UI/未保存状态。

## Phase 3：比赛时间线

恢复：
- 开题；
- 思路世代；
- 首代码；
- 样例；
- Bug；
- 稳定版；
- 优化；
- 切题；
- 提交；
- 交付。

## Phase 4：逐题研究谱系

每题：

```
模型0 [H/P/E]
↓
为什么出现
↓
什么证据支持
↓
反例/漏洞
↓
留下哪些正确事实
↓
下一代模型
...
```

## Phase 5：代码考古

保存关键版本：
- 第一成型；
- 样例全过；
- stable partial；
- 大重构；
- 失败版；
- final。

Bug：
- 产生；
- 发现；
- 修复；
- 复发；
- 最终幸存。

## Phase 6：独立验证

优先级：
1. proof
2. official sample
3. brute
4. exhaustive/random
5. checker audit
6. sanitizer
7. stress

先验证 oracle/checker/sample 自己。

## Phase 7：战略复盘

区分：
- 赛时已发现资产；
- 赛后 hindsight；
- 已冻结资产；
- 只是口头资产；
- 每20分钟预期得分；
- 机会成本。

如果用户说“这X分一定能拿”：
**10分钟内必须物化。**

## Phase 8：题解

按“比赛里怎么想到”讲：

1. 人话；
2. 手玩；
3. brute；
4. 正确性；
5. 重复计算；
6. 从赛时思路往前推；
7. 正解；
8. proof；
9. complexity；
10. code；
11. minimal hack；
12. 下次识别信号。

## Phase 9：仓库

完整场次检查：

- README
- 复盘报告
- 题解
- 全过程复现
- 研究过程深挖
- 赛时代码逐段解剖
- Replay×录音时间线
- 结果核对
- 资料完整性报告
- 验证报告
- 历史代码版本
- 正解
- brute/verify
- 原始材料索引
- 可视化

根目录：
- README
- 错因档案
- 赛前执行卡
- 阶段总结
- 覆盖矩阵
- AI_HANDOFF

# 证据标签

- [P] proof
- [E] exhaustive/brute
- [C] checker/statement
- [H] hypothesis
- [X] counterexample
- OJ-AC
- BRUTE-VERIFIED
- PROVED

# 禁止事项

- 不读录音只看摘要；
- 不解ZIP；
- 只看最终cpp；
- 实时榜单直接算完赛均分；
- 把未开始账号算0分选手；
- 把最终短文件解释成“中间没做过”；
- 用赛后发现的partial批评“赛时明明已经会”；
- 把环境事故当算法失败；
- 反过来用环境事故洗掉真实代码Bug；
- 仓库只加README就宣布完成。

# 最终自检

在宣布完成前回答：

- 我能指出用户每题至少两代思路吗？
- 我能指出关键结论对应录音时间或代码SHA吗？
- 我是否区分赛时已知与赛后 hindsight？
- 我是否保存关键历史版本？
- 我是否审过 oracle/sample？
- 我是否更新跨场结论？
- 下一位 AI 能否只靠仓库接管？

有关键项回答“不能”，继续工作。
