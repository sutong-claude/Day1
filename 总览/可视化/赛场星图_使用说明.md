# 赛场星图 · CSP-S Evidence Atlas

> 2026-10-12 实装。**真实交互式单文件网页**，不是截图、PPT 或静态效果示意。

## 从哪里打开

**优先：下载并直接打开 [赛场星图_2026-10-12.html](../赛场星图_2026-10-12.html)**。它把数据、样式和 JS 全部内嵌在同一个 HTML 里：断网也能搜索、筛选、点开题目、切换事件、查看得分曲线、导出 CSV。不需要 npm、Python 服务、数据库或登录。仓库根目录另有同一文件的 `赛场星图.html` 别名。

从 GitHub 的普通 `blob` 页访问 HTML 时，GitHub 显示的是文件预览/代码，不保证以网页运行：应点击下载或 `Raw` 后在本地打开。**仓库 Pages 托管有没有开启须另外核验**，不能先宣称有在线域名。

## 已经真做出的功能

- 首页深色太空控制台、Canvas 星点、SVG 轨道和响应式移动排版；支持系统偏好 `prefers-reduced-motion`。
- 八场正式分数曲线；图上八个节点能点击并更新焦点，场次一律按官方比赛结束时快照计分。
- Day1—Day8 × A/B/C/D 的 32 宫格热图，每格一键打开完整题目档案。
- 按总表程序解析的**36个题目**：32 道代码源题+4道CodeLands题；支持题名、题目现状、算法描述、下场触发器全文搜索。
- 平台、Day、得分状态过滤；支持导出当前筛选结果 CSV。
- 独立案例抽屉：赛时成绩/状态、赛时思考、赛后算法闭合状态、来源可靠性、下步任务和 GitHub 比赛目录链接。
- 11个真实证据转折：Day3 checker误绿、Day4 oracle污染、Day7 B回滚+D20代、Day8 A abs/C下标等，事件导航可切换。
- 证据统计：三包、113次Replay保存、282条聊天消息与6处原始截断；明确字节扫描不等于逐段语义闭合。
- 六项 P0/P1 持续任务，特别强调Day8赛时15与赛后A70/C23分层。

## 验证方式

从仓库根目录：

```bash
node tools/verify_star_atlas.mjs
npm install --no-save --no-package-lock playwright@1.56.1
npx playwright install chromium
node tools/smoke_star_atlas.mjs
```

浏览器测试打开真正的本地文件，模拟搜索、筛选、打开详情、Esc关闭、事件切换、CSV下载、移动布局，并留下完整截图。若 CI 因 Runner/下载限制没运行或失败，状态应如实记为未验收；不能因为测试代码存在就写“浏览器实测已过”。

## 数据与隐私边界

最初36题来源是仓库的 `全题总表_2026-10-11.md`，于2026-10-12自动拆表并校验：36个不重复ID、32题代码源赛时得分总和669、8天分数各对应。交接报告提供具体原始来源与错误原因。

这是公开仓库，网页**不包含**录音、视频、键盘/剪贴板、私密聊天全文、账号页面和用户个人识别信息。授权Library中仍保存原件；该前端的“证据卡”是可追溯的摘要，不是原件全文，也不能让第三方绕过权限读取Library。

赛时Day8 15/400；赛后A70来自用户粘贴的OJ逐点文本，C23来自用户陈述，均尚未独立抓到新的官方record。算法证明/本地实验/OJ-AC始终分开。CodeLands200/400属于另一个评分体系，不计入八场669分。
