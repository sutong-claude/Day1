## 3. A：健康范式

A 的结构被快速压成“按父亲分兄弟组”。

最大值：
- 每个兄弟组先取一个最大正权；
- 全局最多允许额外出现一对兄弟，因此再从所有组的“第二大正权”里取一个最大的。

最小值对称：
- 每组取最负；
- 再从所有组第二负候选里取一个最负。

这是非常值得保留的建模模式：

> **每组至多 1 个 + 全局允许一次额外违规  
> = 各组基础最优 + 一次全局最大边际收益。**

最终代码一交 100。Day6→Day7 连续两场说明：数学对象清楚时，实现能力已经能稳定兑现。

## 4. B：数学定义基本正确，复杂度转换没完成

赛时代码完全照题意递归：

1. 当前连通块找排列中最靠前的点；
2. 删除它；
3. 对每个剩余连通块重复。

这就是正确的朴素定义，所以 B 的 45 不是随机骗分：前两档 20+25 全过。

### 直接 RE 放大器：递归层层保留 unordered_set

`calc()` 把当前连通块全部插入一个 `unordered_set`，但这个集合之后根本没有被读取。

在链形恶劣数据中：

- 第一层集合约 n；
- 递归进入第二层时第一层仍活着，第二层约 n-1；
- 再下一层约 n-2；
- ……

同时存活元素规模可到 O(n²)，与 227.2 MiB 后 RE 的表现吻合。

### 即使删掉 set，仍然不是满分

每删一个点，都重新 DFS 扫剩余连通块找最早优先级：

n + (n-1) + ... = O(n²)。

因此 set 是内存炸弹，但根本满分瓶颈是**重复扫描整个连通块**。

## 5. B 的真正复杂度跃迁：把删除倒放

正向过程：

```
删点 -> 连通块分裂
```

动态维护分裂很难。

把排列倒着处理：

```
加点 -> 若干连通块合并
```

这就变成并查集。

倒序加入 v 时，已经加入的点优先级都比 v 低。v 每个已激活邻居所在的 DSU 连通块，在正向递归中恰好是“删除 v 后产生的一个下级组”；该块当前负责人直接向 v 汇报。随后把这些块和 v 合并。

复杂度可做到 O(n α(n))。

这题以后应形成自动触发器：

> **固定顺序删点 + 删除导致连通块分裂 → 第一反应试逆序离线 + DSU。**

## 6. 最大机会成本不是 B 少的 55 分

C 至少存在两条很直的特殊性质：

- v=50：每局胜率恒 1/2，目标方案连赢 r 局，概率为 (1/2)^r：10 分。
- L=R=1 或 2^r：目标方案始终是极端优先级，概率退化为 p^r 或 (1-p)^r：15 分。

D 的 N≤100 子任务可做暴力：19 分。

所以非常现实的 score floor 是：

**100 + 45 + 25 + 19 = 189。**

这不是说赛时“必然能拿189”，而是说明 B 在长期没有复杂度突破时，C/D 至少 44 分的单位时间收益明显更高。

新版榜单也能看到多名 189 分选手，进一步说明 19 分 D partial 是实际可兑现资产。

## 7. Day7 后新增规则

1. 已写出正确暴力定义但复杂度仍 O(n²) 时，禁止只做微优化；必须回答“重复计算是什么？能否逆序、离线、增量、DSU、单调结构？”
2. T+2:00 必须形成全场 **score map**，例如 A100 / B45 / C25 / D19，而不只是“题都看过”。
3. 已有100分后更要执行切题纪律；安全垫不是死磕许可证。
4. 最后30分钟优先冻结 C/D 这种完整子任务，不再赌一个大题剩余的几十分。
