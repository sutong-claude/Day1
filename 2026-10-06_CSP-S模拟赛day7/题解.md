# A 兄弟

## 题目压缩

兄弟关系只看父亲，所以树的祖孙结构不重要。

对每个父亲的一组孩子：
- 若合法集合中这个组只选 0/1 个，不产生兄弟对；
- 若选 2 个，产生恰好 1 对兄弟；
- 任何组选 3 个会产生至少 3 对兄弟，必非法；
- 全局最多有一个组能选 2 个。

根节点 1 没有兄弟约束，可独立选择。

## 最大值

根：
- a1>0 就选。

每个兄弟组：
- 只考虑正权；
- 最大的一个可以正常选；
- 第二大的正权是“使用唯一兄弟特权”时的额外收益。

因此：

~~~text
ans = 根的正贡献
    + 每组最大正权
    + 所有组第二大正权中的最大值
~~~

不存在正 second 时额外贡献为 0。

## 最小值

完全镜像：
- 根负则选；
- 每组选最负的一个；
- 全局再从各组第二负中取最负的一个。

复杂度 O(n) 即可；赛时 priority_queue 版也能通过。

# B 凯瑟琳的委托分组

## 20/25 分：定义直译 O(n²)

rank[x] = x 在排列中的位置。

当前组件：
1. 找 rank 最小的 root；
2. root 的 boss 是上一级负责人；
3. 删除 root；
4. 每个剩余组件递归。

可每次 DFS 扫组件找最小 rank。

这就是赛时拿到 45 的核心模型。

## 满分：反向加点 + 并查集

原过程的难点：
> 删除一个点会让一个组件分裂成多个组件。

动态维护 split 很难。

反向处理优先级：
p_n, p_{n-1}, ..., p_1。

此时是不断**加点**。

加入 v=p_i 时：
- 已激活点优先级都比 v 低；
- v 会连接若干已激活组件；
- 每个组件已经有自己的当前最高负责人 leader；
- 在原删除过程中，v 被删以后这些组件正是它的下级组，所以这些 leader 的直属上级就是 v；
- 然后把这些组件和 v 合并；
- 新组件 leader=v。

伪代码：

~~~text
for i = n .. 1:
    v = p[i]
    active[v] = true
    make_set(v)
    for y in neighbors(v):
        if active[y]:
            c = find(y)
            boss[leader[c]] = v
            union(c, v)
    leader[new_component] = v

boss[p[1]] = 0
~~~

复杂度 O(n α(n))。

已用随机小树与 O(n²) 定义直译 oracle 对拍通过。

# C 砂糖的培养方案

## Subtask 2：v=50，10 分

p=1/2。

无论目标方案 k：
- 对手优先级高还是低；
- 怎么配对；
- 是否根据历史自适应；

目标每场晋级概率都恰好 1/2。

夺冠必须连续赢 r 场：

~~~text
P(k) = 2^{-r}
~~~

对所有 k 相同，所以期望也是 2^{-r}。

## Subtask 3：L=R=1 或 L=R=2^r，15 分

若 k=1：
- 它永远是更高优先级；
- 每场赢的概率 p；
- 冠军概率 p^r。

若 k=2^r：
- 它永远是更低优先级；
- 每场赢的概率 1-p；
- 冠军概率 (1-p)^r。

这两个 subtask 合计可做出一个很短的 25 分 special。

# D 提纳里的巡林路线

## Subtask 1：N<=100，19 分机械暴力

只枚举叶子对 A<B。

预处理全点对距离 d[u][v]。

树上一个点 x 到路径 P(A,B) 的距离有经典公式：

~~~text
dist(x, P(A,B))
= ( d(x,A) + d(x,B) - d(A,B) ) / 2
~~~

因此对每个叶子对：
- len=d[A][B]；
- H=max_x (d[x][A]+d[x][B]-len)/2；
- value=H*len；
- 维护最大值与无序叶子对数量。

n<=100 时 O(n³) 足够。

已验证三个官方样例：
- 6 2
- 2 3
- 0 1

## Subtask 2 / Full

用户赛时尝试了“固定根 + 子树内两条深链 + 外部最深”的分解，但它没有覆盖任意叶子对主路径，已被样例/调试否定。

当前不要把该模型继续包装成 52 分算法。

后续补题优先：
1. 先保留 O(n³) oracle；
2. 对 n<=5000 寻找 O(n²) 或 O(n² log n)；
3. 再研究 5e5 的 full；
4. 任何“直径/换根”猜想先和 oracle 对拍。
