# Day7 四题题解 / 赛场突破口

> 重点不是只写答案，而是回答“比赛时怎么从朴素想法走到下一层”。

# A. 兄弟

## 1. 先把限制翻成人话

兄弟关系只取决于父亲。

要求选出的点集中：

> **最多只能出现一对兄弟。**

因此不同父亲对应的孩子天然分成若干组。

## 2. 最大值

如果完全不允许兄弟重复，那么每组最多选一个，显然：
- 只拿正权；
- 每组拿最大的正权。

题目又允许**全局多出现一对兄弟**。

所以在上述基础解上，只可能有一个组再多拿一个点。这个额外点应该是：
- 某个组的第二大正权；
- 在所有组第二大中取最大。

根节点没有兄弟，可独立按正负决定选不选。

最小值完全对称：
- 每组先取最负；
- 再全局补一个“第二负”里最负的。

## 3. 可迁移模型

```
每组容量 1
+ 全局允许一次容量 +1
= 各组基础最优 + 一次最大边际收益
```

这类题不要一上来 DP；先问“限制是不是按组可分”。

# B. 凯瑟琳的委托分组

## 1. 赛时朴素递归为什么是对的

题目定义本身就是：

```
当前连通块
→ 找 p 中最靠前的点 v
→ v 当负责人
→ 删除 v
→ 对每个剩余连通块递归
```

所以直接 DFS 当前块找最小 rank，本身就是正确 brute。

赛时前 45 分能过，正是因为这个数学模型没有错。

## 2. 真正瓶颈：每层都在重扫

链形最坏：

```
n + (n-1) + ... + 1 = O(n²)
```

赛时代码的 unused `unordered_set` 又让递归时多层大集合同时存活，进一步把内存推到 227.2 MiB 后 RE。

但**删掉 set 只修 RE，不会修满分复杂度**。

## 3. 怎么想到反向 DSU

看到：

> 删除一个点以后，连通块会分裂。

动态维护“分裂”通常难。

固定删除顺序时，应自动问：

> **把录像倒放会怎样？**

倒放后：

```
删除点 -> 加入点
连通块分裂 -> 连通块合并
```

合并就是 DSU 最擅长的事情。

## 4. 倒序过程

从 `p[n]` 到 `p[1]` 激活。

加入 v 时：
- 已激活的点优先级都比 v 低；
- v 的每个已激活邻居属于一个不同的活跃连通块（原图是树）；
- 每个连通块当前 DSU 根，就是该块在 p 中最靠前的点，即该块负责人；
- 正向删除 v 时，这些块恰好会成为 v 的下级组。

因此对每个活跃邻接块根 r：

```
ans[r] = v
union(r, v)
```

并强制新 DSU 根为 v。

最终 p[1] 没有上级，答案为0。

复杂度：

```
O(n α(n))
```

代码：`正解代码/B_反向并查集.cpp`。

## 5. 触发器

以后见到：

```
固定顺序删除
+ 删除后问连通块/分裂结构
```

第一反应：

```
逆序加入 + DSU
```

# C. 砂糖的培养方案：赛时已发现10分，赛后再补15分

满分概率策略很深。二次取证后必须区分：**v=50 的10分是赛时本人已经推出来的；L=R 极端排名15分是赛后补出的简单性质。**

## v = 50（10分）

高优先级方案赢一局概率：

```
p = 1/2
```

低优先级也是 1/2。

无论怎么配对，目标方案要最终存活都必须连赢 r 场，因此：

```
P = (1/2)^r
```

k 和配对方式都消失。

## L=R=1 或 L=R=2^r（15分，赛后补出）

关注方案固定是全局最高或全局最低优先级。

- k=1：每局都是高优先级，最优概率 `p^r`；
- k=2^r：每局都是低优先级，概率 `(1-p)^r`。

这两个包不需要先解满分博弈。

# D. 提纳里的巡林路线：N≤100 的19分

目标枚举两片叶子 A,B：
- 主路线是它们唯一路径；
- `dist(A,B)` 是路径长度；
- H 是全树点到该路径的最大距离；
- 最大化 `H * dist(A,B)`，同时计数。

N≤100 时完全可以朴素：

1. 枚举叶子对；
2. DFS/BFS 还原 A-B 路径；
3. 多源 BFS 从路径所有点出发，求每点到路径距离；
4. 取最大 H；
5. 更新最大值与方案数。

叶子对 O(N²)，每对 O(N)，甚至更粗暴也足够。
