## A　蜗蜗的记录带

**题意**：1～n 的排列，最多翻转一个区间，问逆序对最多多少。多组数据，**Σn ≤ 8000**，1.5 秒。

**核心结论**：翻转 [l, r] 只影响“两个数都在区间内”的点对：顺序对和逆序对互换。区间外、跨区间的点对都不变。
所以收益 = 区间内顺序对 − 区间内逆序对 = C(len, 2) − 2·inv(l, r)。
答案 = 原逆序对数 + max(0, 最大收益)。

**复杂度按 Σn 算**：O(n²) = 6.4×10⁷，够。

### 正解：固定右端点增量维护，O(n²)

inv(l, r) = inv(l, r−1) + [l, r−1] 里比 a[r] 大的个数。
枚举 r，让 l 从 r−1 往左走，cnt 累计“比 a[r] 大的个数”，f[l] += cnt，f[l] 就是 inv(l, r)。不需要任何数据结构。

代码：`正解代码/A_记录带_On2.cpp`。另一份 `A_记录带_赛时代码只换树状数组.cpp` 保留你的结构，只把 multiset 换成树状数组（O(n² log n)，最大数据 0.57 秒）。

**两个坑**：
- 区间逆序对**不能**用“前缀逆序对相减”：点对跨越 l 的部分会被算进来。反例 `[3, 1, 2]`。
- `std::distance` 在 set/multiset 上是 O(距离)，不是 O(log n)。数“比我大的个数”用树状数组。

## B　蜗蜗的联动面板

**题意**：n 个格子，a 单调不降。一次操作：选格子 i，读它的值 x（1 ≤ x ≤ n），把**第 x 号格子**加 1。问能否变成 1～n 的排列，能就输出操作序列。

### 判定：有解 ⇔ 对所有 i，aᵢ ≤ i

**必要性（抽屉原理）**：数只增不减。若 aᵢ > i，位置 i..n 这 n−i+1 个数最后都 ≥ i+1，但 [i+1, n] 只有 n−i 个值，放不下。
**充分性**：下面的构造。（n ≤ 7 的全部 2353 个数组暴力验证过。）

操作次数固定为 n(n+1)/2 − Σa（每次总和 +1）。

### 部分分

- 子任务 1（Σn ≤ 8，15 分）：DFS 搜操作序列。
- 判定写对就能拿所有 NO 的点。

### 构造：归纳 + 链式上推，O(n²)

假设前 i−1 个位置已经是 1～i−1 的排列，加入位置 i，值 t = aᵢ ≤ i：
- t = i：直接成立。
- 否则值 t 有两个人持有，值 i 没人持有。按 v = t, t+1, …, i−1 依次：把“原来持有 v 的那个位置”加 1，推到 v+1。

**为什么每步合法**：要给位置 x 加 1，需要有人的值等于 x。推的过程中 1～i−1 始终都有人持有（被推走的值由刚推上来的位置或位置 i 顶上），而 x ≤ i−1。

代码：`正解代码/B_联动面板.cpp`（5 组大样例 + n ≤ 8 的 33097 个数组全部通过）。

**识别信号**：构造题先解决判定（写暴力打表、看 checker）；“只增不减 + 最后是排列” → 抽屉原理；“前 i−1 个排好了，加入第 i 个怎么修” → 归纳构造。

## C　蜗蜗的晶体树阵

**题意**：n 个点的树，每个点三选一：恒稳得 mᵢ；共振得 wᵢ（需要有邻居是核，或自己到 k 号点距离 ≤ L）；核得 0（让所有邻居能共振）。多次询问 L，求最大总分。

### 部分分（一共 70）

- 子任务 1（wᵢ = 1，10 分）：mᵢ ≥ 1 = wᵢ，共振从不更好，答案 Σmᵢ。
- 子任务 2（q = 1 且 L = n，10 分）：所有点都在半径内，答案 Σmax(mᵢ, wᵢ)。
- 子任务 3、4（n, q ≤ 5000，50 分）：每次询问做一遍下面的 DP，O(nq)。

### 正解：以 k 为根，O(n + q)

对每个点 v（儿子记为 c）：
- `core(v)`：v 当核 = Σ g1(c)
- `g0(v)`：父亲**不是**核时子树最大值
  = max( core(v),  m_v + Σg0(c),  w_v + Σg0(c) + max_c (core(c) − g0(c)) )（最后一项：挑一个儿子当核来支撑 v）
- `g1(v)`：父亲**是**核（或 v 在半径内，能自由共振）时子树最大值
  = max( core(v),  max(m_v, w_v) + Σg0(c) )

**询问 L 的答案** = 深度 < L 的点的 Σmax(m, w) + 深度 = L 的点的 Σg1。
- 深度 < L：自己和所有邻居都在半径内，当核没好处，直接取 max(m, w)。
- 深度 = L：自己能自由共振，等价于“父亲是核”，但仍可能值得当核去支撑下一层，这已包含在 g1 的 core 选项里。

按深度预处理前缀和，每次询问 O(1)。

代码：`正解代码/C_晶体树阵.cpp`（4 组大样例 + 300 棵小树和 3ⁿ 暴力比对）。

**识别信号**：“要有一个邻居是 X 才能选 Y” → 支配型三状态 DP（洛谷 P2458 保安站岗）；“离某点 ≤ L 的部分被豁免” → 以它为根按深度分层；子任务里出现 “L = n”“w = 1” → 先想是不是退化成了平凡情况。

## D　蜗蜗的轮换密钥

**题意**：能否构造 f：{1..n} → {1..n}，f(x) ≠ x，且 f 做 k 次后每个 x 回到自己？n ≤ 10¹⁸，k ≤ 10¹⁵，不同的 k 最多 50 个。

**转化**：
1. fᵏ = 恒等 ⇒ f 是排列，分解成若干环，每个环长整除 k；f(x) ≠ x ⇒ 环长 ≥ 2。
2. 问题变成：n 能否写成若干个“k 的 ≥ 2 的约数”之和。
3. 任何 ≥ 2 的约数都是某个质因子 p 的倍数，长 d 的环可拆成 d/p 个长 p 的环 ⇒ **n 能否写成 k 的质因子的非负整数组合**。

（不要求 k 是最小正周期，所以不需要“乘积 = k”或 lcm = k。）

### 部分分（一共 45）

- 子任务 1、2（n, k ≤ 1000，25 分）：对 k 的约数做完全背包。
- 子任务 3（n ≤ 10⁶，20 分）：对 k 的质因子做完全背包，每个不同的 k 做一次。

### 正解：按质因子个数分类

先筛 √(10¹⁵) ≈ 3.2×10⁷ 以内的质数，给每个不同的 k 分解质因数。
- k = 1：NO。
- 一个质因子 p：n % p == 0。
- 两个质因子 p < q：n = ap + bq。取 b ≡ n·q⁻¹ (mod p) 的最小非负值，检查 b·q ≤ n（NOIP 2017 小凯的疑惑的思路）。
- 三个及以上：最小质因子 p₁ ≤ ∛(10¹⁵) = 10⁵。**同余最短路**：dist[r] = 能凑出的、模 p₁ 余 r 的最小数，用其余质因子当边跑 Dijkstra。n 可行 ⇔ dist[n mod p₁] ≤ n。

代码：`正解代码/D_轮换密钥.cpp`（3 组大样例 + n, k ≤ 60 的 3600 组和背包比对）。

**原题**：Codeforces 986F *Oppa Funcan Style Remastered*。同余最短路练习：洛谷 P3403 跳楼机、P2371 墨墨的等式。
