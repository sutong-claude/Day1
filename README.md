# 集训模拟赛

一个仓库管所有模拟赛。每场一个文件夹，跨比赛的东西放在根目录。

## 赛前必读

- [赛前执行卡](赛前执行卡.md)：思路上的四个“换”、每道题的六步、时间检查点、突发情况
- [错因档案](错因档案.md)：跨比赛累积的病因表和待补专项
- [阶段总结 Day1-Day4](阶段总结_Day1-Day4.md)：四场能力变化、Day4 归零链、下一阶段工程优先级
- [赛中研究协议](赛中研究协议.md)：把结论标成 P/E/C/H/X；猜想优先自动找最小反例；用信息增益决定是否继续深挖

## 每场文件夹里有什么

| 内容 | 位置 |
|---|---|
| 复盘报告（md + pdf） | `复盘报告.md` |
| 题解（只讲题：部分分 + 正解 + 为什么对） | `题解.md` |
| 验证过的正解 | `正解代码/`（Day2 起另有 `正解代码/暴力/`：每题能拿子任务分的暴力） |
| 赛时代码各版本（文件名带北京时间） | `赛时代码/` |
| 动画讲义（浏览器直接打开） | `动画讲义/` |
| 原始材料（归档、录音转写、虚拟机导出，原样保存） | `原始材料/`（Day2 起） |
| 深度赛场复现（Day3 起） | `比赛全过程复现_完整版.md`、`研究过程深挖.md`、`赛时代码逐段解剖.md`、`可视化复盘/` |
