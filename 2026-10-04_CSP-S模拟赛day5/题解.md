# A. 蜗蜗的三角画布｜赛时接近 full，真正缺的是 first-by-position

## 1. 把几何压成 endpoint

令：

[
r_i=i+d_i.
]

第 i 个三角形斜边：

[
y=r_i-x.
]

所有斜边斜率完全相同。

所以右边三角形 j 若：

[
r_j<r_i
]

它在与 i 重叠的区间里始终压在 i 下方，不会接管上包络。

因此真正需要的是：

[
nxt(i)=min{j>imid r_jge r_i}.
]

注意关键词：

> **位置最小。**

不是：
> 满足条件的 endpoint 值最小。

这就是 Day5 最核心的语义差异。

## 2. 为什么 lower_bound / upper_bound 错

赛时第一版按 endpoint 值排序后 lower_bound。

它解决：

[
min r_j,quad r_jge r_i
]

题目需要：

[
min j,quad j>i, r_jge r_i.
]

两者不同。

第二版甚至在没有保持有序的 vector 上直接二分，连二分前提也不成立。

## 3. 正确工具：Next Greater or Equal

从右往左维护单调栈：

```cpp
while (!st.empty() && r[st.back()] < r[i])
    st.pop_back();

nxt[i] = st.empty() ? n + 1 : st.back();
st.push_back(i);
```

具体 `>` / `>=` 按题目边界定义统一。

本质：

> 右边第一个 endpoint 足够高的位置。

## 4. suffix DP

若：

[
j=nxt(i)
]

并且 j 还落在当前三角形水平范围内，令：

[
h=j-i.
]

i 在 ([i,j]) 这一段主导包络，二倍面积为：

[
h(2d_i-h).
]

因此：

[
f_i=f_j+h(2d_i-h).
]

若不存在有效 blocker：

[
f_i=d_i^2+f_{min(i+d_i,n+1)}.
]

## 5. 赛时为什么会感觉“修了一百个 Bug”

前半场确实有很多独立实现 Bug：
- STL 接口；
- iterator；
- pair first/second；
- off-by-one；
- 越界；
- DP 下标；
- h 定义。

但第二版后期这些大多被修掉。

最后大量症状主要来自同一个上游错误：

```text
blocker query 错
↓
f[i] 错
↓
更左边继续引用 f[i]
↓
整个 suffix 污染
```

所以：
> 症状很多 ≠ 最终还有几十个独立 Bug。

## 6. 赛后验证

正确单调栈版：
- 官方附件输出一致；
- 80,000 组小随机与直接几何 brute 一致。

这题是“数学对象先于数据结构名字”的长期模板。

## 2. n=1 special 的具体 Bug

代码用：


这里的 n 是：
> 日志条数。

但 `substr` 的枚举范围应该由：
> 字符串长度
