# Day5 赛后补题进展（2026-10-05）

## A 三角画布

### 当前状态

赛时核心 DP / 几何已经接近正确，主要失败在 blocker 查询。

赛后已经把查询重写成单调栈：

~~~text
r_i = i + d_i
next[i] = 右边第一个 r_j > r_i 的位置
~~~

这和赛时“按 endpoint 值做 lower_bound / upper_bound”是根本不同的对象。

### 本次又发现的一个笔误：n+1 sentinel

不存在 next greater 时：
~~~text
next[i] = n+1
~~~

早期赛后版没有先排除这个 sentinel，就拿它进入“真实 blocker”分支。

最小反例：

~~~text
n=1
d1=2
~~~

错误会把 n+1 当成真正接管位置，面积算成 3；
正确是整三角形 4。

修正后：
- sentinel 先排除；
- 再判断 blocker 是否在当前三角形结束前。

### 目前应保留的复盘点

1. 题目要的是“最小位置”，不是“最小值”；
2. strict next-greater 是自然定义；
3. equal endpoint 对包络没有新的接管意义；
4. sentinel 不能参与普通状态转移；
5. 这题不应再被总结成“整套 DP 都错了”。

## B 巡检路线

赛后已完成核心建模讲解：

1. 找出 A_i < B_i 的“坏区间” [A_i,B_i]；
2. 这些区间左右端点都递增；
3. 一次回头可以同时解决一段连续坏区间；
4. 得到分组 DP；
5. 转移可拆式优化。

补题时重点不要只抄 full：
- 先写 O(m²) 分组 DP；
- 手玩样例确认“一次回头覆盖连续一组”；
- 再优化。
